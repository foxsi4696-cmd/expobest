# Expobest Platform

Рабочий MVP платформы Expobest: публичный каталог, поиск, вход, ролевая
админ-панель и SQLite-база данных с REST API. Данные не зашиты в HTML — их
отдаёт backend из `data/expobest.sqlite`. Первый запуск импортирует
демонстрационные данные из `data/db.json`.

## Запуск

```powershell
node server.js
```

Откройте `http://localhost:3000`.

Демо-доступ: `admin@expobest.kz` / `Admin123!` или
`editor@expobest.kz` / `Editor123!`.

## Реализовано

- Публичные разделы: компании, студенческие компании, товары, услуги,
  студенты, университеты, журнал, поиск и форма отзыва.
- API с фильтрацией, пагинацией, CRUD, подпиской, модерацией отзывов.
- Роли Admin/Editor и проверка прав на backend.
- Современная адаптивная публичная часть и админ-панель с Dashboard.
- Кастомный неоновый курсор с белым свечением и поддержкой тач-экранов.

## Деплой на Vercel

Проект полностью настроен для деплоя на Vercel (файл `vercel.json` и `api/index.js` уже созданы, поддержка Node.js 22 и SQLite включена):

1. Загрузите проект в репозиторий GitHub / GitLab.
2. В панели [Vercel](https://vercel.com) нажмите **Add New Project** и выберите репозиторий.
3. Оставьте настройки по умолчанию (Framework: **Other**, Root Directory: `./`).
4. Нажмите **Deploy**. Проект сразу будет доступен онлайн.
